Mezanino CRM

Levantamento funcional imobiliário

Formulário Carbon para consolidar as respostas do CRM imobiliário, salvar o resultado em um repositório GitHub e abrir uma notificação para acompanhamento.

Repositório alvo: glaucodeveloper/mezanino-crm
Branch padrão: main

Envio para GitHub

Preencha os campos do levantamento e informe apenas o token pessoal de acesso. O HTML usa esse token para criar um arquivo JSON no repositório e abrir uma issue com o resumo.

O token não é salvo no navegador. O conteúdo fica disponível em localStorage apenas como último rascunho do formulário.
